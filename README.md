# LimSystem — Personal Cyber Portfolio

یک وب‌سایت شخصی چندصفحه‌ای با HTML، CSS و JavaScript.

## اجرا
1. فایل ZIP را استخراج کن.
2. فایل `index.html` را با Firefox یا Chrome باز کن.
3. برای ویرایش متن، فایل HTML مربوط به هر صفحه را تغییر بده.
4. ظاهر سایت در `css/style.css` و افکت بارش باینری در `js/main.js` قرار دارد.

## صفحات
- صفحه اصلی، درباره من، علایق، بازی‌ها، فضای سایبری، پروژه‌ها، ارتباط
- صفحات مستقل برای Elden Ring، War Thunder، Red Dead Redemption 2، Ghost of Tsushima، Assassin's Creed IV: Black Flag و Assassin's Creed Unity

## نکته حریم خصوصی
شماره تماس به‌صورت جای‌نگهدار در صفحه تماس قرار دارد؛ پیش از انتشار عمومی، فقط راه ارتباطی‌ای را درج کن که مایل به عمومی‌شدن آن هستی.

فونت‌های Google Fonts در صورت اتصال اینترنت بارگذاری می‌شوند؛ سایت بدون آن‌ها هم اجرا می‌شود.


## تصاویر بازی‌ها
تصاویر جلد بازی‌ها از میزبان‌های تصویر آنلاین بارگذاری می‌شوند؛ برای دیدنشان هنگام اجرای سایت اتصال اینترنت لازم است.
